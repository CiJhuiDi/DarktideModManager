========================================
  暗潮 Mod 管理器 DarktideModManager Alpha 测试版
========================================

一款为《战锤40K：暗潮》(Darktide) 设计的轻量 Mod 管理器。
基于 Darktide Mod Framework (DMF) 的加载机制，只做"壳"：
帮你管理 mod 启停、加载顺序和方案预设，不干预游戏本体文件。
内置 DMF 全套组件 + 整合包一键导入（可整体替换）+ 归档备份找回。
自己做的 Mod 可以右键标「我的 mod」收进管理器**管理器库**：换包时原地保留并保持启用，
游戏目录被清空 / 误删也能一键从库恢复。

----------------------------------------
【系统要求】
----------------------------------------
- Windows 10 / 11（需自带 Edge WebView2 运行时，Win11 自带，Win10 一般也有）
- 已安装《暗潮》：**Steam 版**完整支持；
  🔬 Xbox app / PC Game Pass 版为**实验功能**——游戏目录自动识别与商店版日志目录已实现，
     但仅经单元测试、**未在真机 Game Pass 环境验证**，遇到问题请回报

----------------------------------------
【怎么开始】（详细步骤见同目录《使用指南.txt》）
----------------------------------------
1. 解压到任意目录，双击 DarktideModManager.exe
2. 程序自动搜索游戏目录（Steam 库 / 🔬 <盘>:\XboxGames）；
   找不到时到左侧「关于」页点「🔍 自动识别」重扫，或「📂 选择文件夹」手动指定
   （选含 bundle 或 mods 的那一层），保存后立即生效
3. 顶部出现红色横幅「✗ 未检测到 DMF 框架」→ 点「⚡ 一键安装 DMF」（只做一次）
4. 点工具栏「📦 导入整合包」选压缩包 → 自动合并 + 打补丁 → 重启游戏即可玩
5. 换包 / 找回旧包：左侧「备份」页是一张表（按今天/本周/更早分组，可搜索排序），
   顶部显示占用与上限、「⚙ 保留策略」可自己调、「🧹 按策略清理」会先列出要删哪些；
   丢了单个 Mod 就点该备份的「🔍 详情」→ 默认勾好「游戏目录里没有」的 →「⤓ 恢复选中」（其他 Mod 不动）；
   要整体回去就点「↺ 整包恢复」（当前 mods 会先自动归档）

   新手上手、界面说明、常见问题速查 → 同目录《使用指南.txt》
   功能全表、构建与测试、目录结构     → 项目主页 https://github.com/CiJhuiDi/DarktideModManager

----------------------------------------
【数据位置】
----------------------------------------
- 启停清单：游戏目录 mods\mod_load_order.txt
- 自动备份：管理器文件夹 backups\
- 方案预设：管理器文件夹 profiles\
- Mod 备注：管理器文件夹 notes.json
- 运行日志：管理器文件夹 app.log（★ 反馈问题时请附上，内含环境诊断）
