========================================
  暗潮 Mod 管理器 DarktideModManager v0.2.2
========================================

一款为《战锤40K：暗潮》(Darktide) 设计的轻量 Mod 管理器。
基于 Darktide Mod Framework (DMF) 的加载机制，只做"壳"：
帮你管理 mod 启停、加载顺序和方案预设，不干预游戏本体文件。
内置 DMF 全套组件 + 整合包一键导入（可整体替换）+ 归档备份找回，新玩家下载后即可开玩。

----------------------------------------
【系统要求】
----------------------------------------
- Windows 10 / 11（需自带 Edge WebView2 运行时，Win11 自带，Win10 一般也有）
- 已安装《暗潮》Steam 版 或 Xbox 版（mods 目录结构相同即可）

----------------------------------------
【快速上手】
----------------------------------------
1. 解压到任意目录，双击 DarktideModManager.exe
2. 程序会自动搜索 Steam 库找到游戏目录（首次启动稍等几秒）
   - 找不到时：左侧「关于」页 → 粘贴游戏目录路径 → 保存 → 重启应用
   - 找游戏目录：Steam 库 → 右键《暗潮》→ 管理 → 浏览本地文件 → 复制地址栏路径
3. 首次使用（新玩家）：若顶部出现红色横幅"✗ 未检测到 DMF 框架"，
   点「⚡ 一键安装 DMF」即可自动装好加载器并激活 mods，全程无需手动找框架
4. 想一步到位？点工具栏「📦 导入整合包」，选择你下载的整合包压缩包
   （zip / 7z / rar / tar.gz，如某某整合包.rar）：
   - 自动解压并识别整合包结构（支持外层套目录）
   - 把包内全部 mod、加载器文件（binaries/mod_loader、bundle/*.patch_999、tools/）
     增量合并进游戏目录，同名旧文件自动备份
   - 自动采用整合包作者的 mod_load_order.txt 启停清单（旧的先备份）
   - 导入完成后自动打补丁激活，重启游戏即可玩
   - 两种导入模式（导入前选择）：
     ·「替换导入」（推荐）：先把当前全部 mod 归档到 backups\pack_backup_时间戳\，
       再换成整合包内容（base/dmf 系统组件保留）——mods 目录始终保持当前一套，
       重复导入多个包不会越堆越多，想换包随时换、旧包可找回
     ·「合并叠加」：把包内 mod 加进现有 mods（同名覆盖，旧版备份）
5. 找回旧包：左侧「备份」页列出全部归档（整合包归档 / DMF 组件备份），
   点「恢复此备份」一键换回（当前 mods 会先自动归档，不会丢）；不需要的备份可删除
5. 界面操作：
   - 拨动开关 = 启用/禁用该 mod
   - 拖拽行 = 调整加载顺序（顺序越靠上，加载越早）
   - 改完点右下角「保存修改」才写入配置文件
   - 「撤销」丢弃本次改动
6. 预设功能：把当前整套启停+顺序存成方案，之后一键切换（如"打宝流"/"拍照流"/"纯净流"）
7. mod 导入：把下载好的单个 mod 压缩包直接拖进窗口，或点「＋ 导入 mod」选择文件，
   自动解压到 mods 目录并加入启用列表
   支持格式：zip / 7z / rar / tar.gz（rar 需要系统已安装 WinRAR 或 7-Zip）
8. 补丁管理：顶部横幅显示 mods 激活状态；点「安装补丁」/「卸载补丁」直接装卸
9. 一键启动游戏：左侧第一个绿色大按钮「▶ 启动游戏」绕过启动器直接启动
   （需先开 Steam 并登录；游戏运行时按钮自动变为"游戏运行中…"并禁用）

----------------------------------------
【功能特性】
----------------------------------------
- 自动识别游戏目录（Steam 多盘库 / 自定义库，config.json 可覆盖；
  原版新装（无 mods 目录）也能识别）
- 归档备份管理（左侧「备份」页）：
  · 列出整合包归档（pack_backup_*，含 mod 数、启停清单标记）与 DMF 组件备份
  · 一键恢复：当前 mods 先自动归档再换回所选备份，补丁自动重打；可删除不需要的备份
- 整合包一键导入（📦 按钮）：
  · 支持 zip / 7z / rar / tar.gz，自动定位根目录（兼容外层套一层目录）
  · 识别标准：含 mods/ 或 binaries/mod_loader 或 bundle/*.patch_999
    （mods/ 下只有一个 mod 且无加载器/清单时视为单 mod，不会误判）
  · 拖拽整合包到窗口也会自动识别并弹出统一模式选择，不会走单 mod 通道报错
  · 两种模式：替换导入（默认，旧 mods 整体归档备份，不叠加）/ 合并叠加
  · 增量合并：包内 mod 文件夹全部拷入（同名旧版自动备份 .bak_时间戳），
    加载器文件（mod_loader / patch_999 / tools/）一并拷入
  · 采用包内 mod_load_order.txt（作者推荐清单，旧清单先备份）
  · 根目录说明/脚本文件（bat/txt/md）不再导入，避免反复装包堆积重复文件；
    替换导入时自动把游戏根目录已有的散文件归档到 backups\root_cleanup_*（可恢复，
    mod_load_order.txt 参考副本与 steam_appid.txt 除外）；bundle_database.data 不导入（防版本冲突）
  · 导入后自动打补丁激活（游戏运行中则退出后自动补）
- 内置 DMF（Darktide Mod Framework）全套组件：
  · 加载器 base（mod_manager + function/*，负责读取 mod_load_order.txt 并按序加载 mod）
  · DMF 本体（mods/dmf，含中文汉化，与官方 GitHub master 核心一致）
  · tools/dtkit-patch.exe + 自动装载插件 _dt_mod_autopatch.dll
  · 自动检测：缺组件时顶部红色横幅提示，一键安装（已有文件先备份到 backups\dmf_backup_*）
  · 安装后自动打补丁激活 mods，并恢复自动装载插件
  · 新玩家拿到管理器即可用，无需自己找框架（内置组件来自实测可用的整合包环境）
- 完整 mod 列表：解析 .mod manifest 显示版本号，支持搜索与筛选，
  标记清单里有但磁盘上已缺失的 mod
- 启停 + 拖拽排序（SortableJS），显式「保存修改」才写盘，可「撤销」；
  每次写入自动备份（exe 旁 backups 目录，保留 10 份）
- 方案预设：保存 / 应用 / 删除，一键切换整套启停+顺序
- mod 导入：拖拽或点击（zip / 7z / rar / tar.gz），自动识别真实 mod 名
  （兼容 Nexus 版本后缀目录）、旧版自动备份（.bak_时间戳，冲突自动加后缀）、
  路径穿越防护
- 补丁管理：
  · 补丁状态权威检测（读 bundle/bundle_database.data 是否含 patch_999 引用）
  · 一键安装 / 卸载补丁（调用 tools\dtkit-patch.exe --patch / --unpatch）
  · 自动装载：启动游戏前自动补打补丁；手动卸载后自动装载一并禁用，
    mods 保持禁用直到手动重新安装
- 一键启动游戏：绕过启动器直接启动（Steam 版 / Xbox 版），
  带三重保护（游戏运行中 / Steam 未登录 / 找不到 exe 都会拦下）
- 防崩溃设计：卸载补丁时绝不动 patch_999 / mod_loader / bundle 文件，
  只通过禁用自动装载 + 还原数据库实现"真正禁用"
- 单实例保护（重复打开弹提示）、窗口位置记忆、动态端口、日志文件 app.log

【常见问题】
----------------------------------------
Q: 杀毒软件报毒 / 被拦截？
A: 本程序是开源的 Python 打包产物，无任何恶意行为。
   PyInstaller 打包的程序常被 Defender/360 等误报，请添加信任或白名单。
   （介意可自行用源码构建，见下方「构建」一节）

Q: 游戏更新后 mod 全部失效？
A: 这是 DMF 机制，游戏更新会重置 mod 加载。需要重新打补丁：
   打开本管理器点「安装补丁」即可恢复（管理器已接管补丁，无需再运行
   toggle_darktide_mods.bat 等脚本）。

Q: 新玩家第一次用，mods 加载不了？
A: 顶部红色横幅提示缺 DMF 框架时，点「⚡ 一键安装 DMF」即可：
   管理器会把内置的加载器 base、dtkit-patch、自动装载插件释放到游戏目录
   （已有文件自动备份），并自动打补丁激活 mods。之后再导入 mod 压缩包就能用。

Q: 提示"未找到游戏目录"？
A: 按「快速上手」第 2 条手动设置目录即可。Xbox 版请填游戏实际安装目录。

Q: 端口被占用？
A: 程序会自动选择空闲端口，一般无需关心。

Q: 改了没生效？
A: 记得点「保存修改」；且加载顺序的改动在下次启动游戏时生效。

Q: 预设/备份存在哪？
A: exe 同目录下的 profiles / backups 文件夹，重装程序前先备份它们。

Q: 卸载补丁后启动游戏，mod 又自动恢复了？
A: 管理器卸载补丁时会同时禁用游戏的"自动装载"插件，mods 会保持禁用。
   想恢复就点「安装补丁」（会自动恢复自动装载）。

【构建（可选）】
----------------------------------------
需要 Python 3.10+，安装依赖：
  pip install fastapi uvicorn pywebview py7zr pyinstaller

打包（项目根目录执行 build.bat，或手动运行）：
  python -m PyInstaller --noconfirm --clean --onefile --windowed ^
    --name DarktideModManager --icon app.ico ^
    --version-file version_info.txt --add-data "static;static" ^
    --add-data "dmf_payload;dmf_payload" --collect-all webview app.py

输出：dist\DarktideModManager.exe
（更新内置 DMF：把新组件覆盖到 dmf_payload\ 对应路径后重新打包即可）
