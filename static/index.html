    详情
    预设 = 整套启停+顺序快照，一键切换配置
    归档备份 = 导入整合包/恢复时自动保存的旧内容。可看内容、挑单个 mod 恢复，或整包换回
    管理器库 = 你自己设计或私装的 mod 的家，位于 exe 同目录 my_mods\。换包流程不碰它，游戏目录只是部署目标。

    路径

    「自动识别」扫描常见 Steam 库并自动定位游戏目录；「选择文件夹」弹窗手动指定（选含 bundle 或 mods 的那一层）。 保存后立即生效。
    ◈ 实验功能：Xbox / PC Game Pass 版（扫各盘符 <盘>:\XboxGames）与商店版日志目录 （%APPDATA%\Fatshark\MicrosoftStore\Darktide）的支持仅经单元测试，未在真机 Game Pass 环境验证； WindowsApps下的 MSIX 安装无法枚举，需「选择文件夹」手动指定。

    模拟环境（测试专用）

    无需真开游戏，即可测试「游戏运行中锁定 mod 编辑」等防呆逻辑。「模拟游戏崩溃」需在模拟运行生效后使用，模拟游戏异常退出、界面解锁。仅测试用，退出应用前记得停止模拟。

    使用说明

    ① 拨动开关或拖拽调整顺序后，点击右下角 保存修改才写入 mod_load_order.txt。
    ② 撤销丢弃界面改动，回到文件真实状态。
    ③ 每次写入前自动备份到 exe 旁的 backups 目录（保留 10 份）。
    ④ 游戏更新后 mods 会被官方禁用，届时点顶部「启用」即可恢复。
    ⑤ 修改仅在下次启动游戏时生效。
    ⑥ 游戏崩溃与管理器无关：管理器只读写 mods 配置与组件状态，不修改游戏本体；崩溃多为 mod 冲突或版本不兼容，可逐个禁用 mod 排查（操作均有自动备份，可随时恢复）。
    ⑦ 崩溃后点本页「打开控制台日志文件夹」，用记事本看最新 console-*.log 里的报错定位问题。
    ☑ 多选模式：点击或拖动选择日志行，右键菜单复制选中行 · 退出多选
