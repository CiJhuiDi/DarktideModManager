========================================
  暗潮 MOD 管理器 · 快速上手指南
========================================

本工具帮你管理《战锤40K：暗潮》的 Mod：安装框架、导入整合包、
开关 Mod、调整加载顺序、一键启动游戏。全程图形界面，不用碰代码。

项目主页 / 问题反馈：https://github.com/CiJhuiDi/DarktideModManager

----------------------------------------
一、安装（1 分钟）
----------------------------------------
1. 解压下载的压缩包，得到一个文件夹：DarktideModManager_alpha
2. 双击里面的 DarktideModManager.exe
3. 程序自动搜索游戏目录（首次启动等几秒）
   · Steam 版：扫常见 Steam 库；Xbox / PC Game Pass 版（实验功能）：扫各盘符
     默认安装位置 <盘>:\XboxGames\ 下的暗潮目录
   · 如果提示"未找到游戏目录"：点左侧「关于」→ 点「自动识别」重扫，
     或「选择文件夹」手动指定（选含 bundle 或 mods 的那一层；Steam 库 → 右键《暗潮》
     → 管理 → 浏览本地文件），保存后立即生效

----------------------------------------
二、界面速览
----------------------------------------
左侧是图标导航（Mod 管理 / 预设 / 备份 / 管理器库 / 关于）。
想让它显示文字：点最左下的「»」，或按 Ctrl+B。展开状态会被记住。

「Mod 管理」页是三栏：
   未启用 | 已启用 | 详情
· 中间栏带 # 序号，那就是加载顺序（越靠上越早加载）
· 右边栏是你点中的那个 Mod 的详情（版本 / 作者 / 路径 / 备注 / 描述），常驻显示
· 三栏的宽度和左右位置都能拖：拖栏头互换位置，拖中间的分隔条调宽度；
  弄乱了点工具栏「恢复布局」一键还原

三栏上方还有一行诊断条，两个灯：
   DMF 组件     —— 框架装了没、能不能生效
   mod 环境检查  —— 有没有缺依赖、顺序跟作者声明冲不冲突
灯是绿的就不用管；变色时它会自动展开下面的横幅说明问题，点那一项可展开/收起。

第一次打开会有 6 步新手引导，跟着走一遍就基本会用了。
之后想再看：左侧「关于」页 →「重新查看引导」。

----------------------------------------
三、三步开玩
----------------------------------------
① 装框架（只做一次）
   诊断条里「DMF 组件」是红的，横幅写着"未检测到 DMF 组件"时，点「＋ 安装 DMF」。
   程序会把 Mod 框架装进游戏目录并激活，之后不再需要手动操作。

② 装 Mod（二选一）
   · 想省事：点工具栏「导入」选整合包压缩包（如某某整合包.rar）
     → 弹窗选「替换导入（推荐）」，自动装好整套 Mod 和作者排好的顺序
   · 想自己搭配：点「＋ 导入 mod」选单个 Mod 压缩包（zip/7z/rar 都行）
   ★ 自己做的 / 别处单独下的 Mod（整合包里没有的那些）：
     在列表里右键 →「收进管理器库」。
     收进库的 Mod 会存到管理器文件夹的 my_mods\（这是它的"家"），之后：
       · 每次换整合包都原地留住，并按你换包前的启停状态保持启用，不会再被连带清掉
       · 换包前会自动把你游戏目录里的最新版本同步进库（你在游戏目录里改过调试也不怕）
       · 万一游戏目录被清空 / 误删，在「管理器库」页点「部署回游戏」就能恢复
     · 想看清单：左侧「管理器库」页有一张表，列出每个 Mod 的体积、是否已部署、是否启用，
       并可逐行「同步进库 / 部署回游戏 / 打开文件夹 / 移出管理器库」
     （没标记的 Mod 在换包时会被归档到 backups\，可随时找回）
   ⚠ 万一你的 Mod 和别人的撞名（同一个名字）：游戏只能加载一个。
     换包时管理器会保留你的版本（包里那个不装，导入前的预览里也会先提醒你）；
     用「＋ 导入 mod」装别人的同名 Mod 时会先问你要不要覆盖，默认不覆盖。
     想两个都要只能改名——请到你的 Mod 源码里改（目录名、.mod 文件名、里面的路径要一致），
     不要在游戏目录里直接改文件夹名。

③ 开玩
   点左侧绿色大按钮「启动游戏」直接进游戏（需先开 Steam 并登录）。
   管理器会先跑游戏自带的着色器缓存构建器，这一步原版启动器每次启动也会做，
   缓存有效约 2 秒，需要重建时约 14 秒。按钮下方会显示当前缓存大小。
   这一步失败只写日志，不会拦着你进游戏。

----------------------------------------
四、日常使用
----------------------------------------
· 开关 Mod：双击一行切换启用/停用（在左栏拖到右栏 = 启用，右栏拖回左栏 = 停用）
  改完点右下角「保存修改」才真正写进清单
· 调整顺序：在「已启用」栏里拖动行上下移动（越靠上加载越早），保存后下次进游戏生效
· 看某个 Mod 的详情：单击它，右边详情栏会显示版本 / 作者 / 顺序 / 路径 / 依赖 / 描述
· 写备注：详情栏里点「点击写一条」，回车保存、Esc 取消；列表上会显示为"名字(备注)"
· 搜索：顶部搜索框，中文名/英文名都能搜
· 方案预设：左侧「预设」页把当前启停+顺序存成方案（如"打宝流"/"拍照流"），
  一键切换（可搜索、可按时间/名称/mod 数排序）
· 换整合包 / 找回 Mod：左侧「备份」页是一张表，按时间线（今天/本周/更早）列出每次换包
  或恢复时自动归档的旧内容
   · 顶部显示"共几个 · 占用多少 / 上限多少"，点「保留策略」可自己定每类留几个、
     最多占多少；「按策略清理」会先列出要删哪些再确认
   · 丢了某个 Mod → 点该备份的「详情」，里面默认勾好"游戏目录里没有"的那些，
     点「恢复选中」只把它们找回来（其他 Mod 不动）
   · 想整体回到备份时 → 点「整包恢复」（会先给你看差异）
   · 删除备份前会显示它占多大，避免误删唯一的回滚点
· 右键 Mod：
   打开文件夹（看 Mod 文件）
   复制 mod 名
   备注…
   收进管理器库 / 移出管理器库
   删除 mod 文件（进回收站，可找回）
   从清单移除（清理已不存在的残留）
· DMF 组件那一项：
   · 显示"已就绪"就是一切正常
   · 「覆盖安装」用内置组件重装一遍（想更新框架 / 怀疑文件损坏时用），旧文件自动备份
   · 「停用」等于关掉整套 Mod 系统——游戏回到未装 Mod 的原版状态，组件文件不删，
     「启用」随时恢复
· 游戏运行中：界面会锁定 Mod 增删改（按钮变灰）——这是防呆保护，
  关闭游戏后自动恢复；想不真开游戏测试防呆效果，
  可到「关于」页点「模拟游戏运行」（测试专用，用完记得停止）
· 底部语录栏：每进行一次操作自动换一条暗潮官方加载画面语录（310 条），
  点击语录栏也能手动换；纯装饰，不影响功能

----------------------------------------
五、常见问题速查
----------------------------------------
Q: 游戏更新后 Mod 全没了？
A: 正常现象（官方机制：更新会重置 Mod 加载）。打开管理器，如果「DMF 组件」那项
   提示已停用或未生效，点「启用」即可恢复；Mod 文件都还在，启停和顺序也没丢。

Q: 管理器里启用了 Mod，进游戏却没效果？
A: 先看诊断条「DMF 组件」是不是绿的——它管的是"游戏要不要读 Mod 目录"这一层。
   这一层正常后，DMF 框架内部还有一层开关，决定加载后是否生效：
   游戏里按 F4 打开 DMF 的 Mod 选项菜单即可查看/切换。

Q: 诊断条「mod 环境检查」红了怎么办？
A: 它查两件事：缺依赖（写了要某个库但磁盘上没有）、顺序冲突（作者在 info.json 里
   声明了要排在某个 Mod 之后，实际却排在前面）。点横幅上的文字会逐个跳转到问题 Mod，
   行上也有对应标签。缺依赖就把那个库装上；顺序冲突就把这个 Mod 往下拖。

Q: 杀毒软件报毒？
A: 这是 Python 打包程序的常见误报，添加信任即可。源码全公开，无恶意行为。

Q: rar 压缩包导入失败？
A: 需要电脑装了 WinRAR 或 7-Zip 才能解压 rar。zip/7z 不需要。

Q: 我的备份、备注、预设存在哪？
A: 全在管理器文件夹里（backups / notes.json / profiles），重装程序前先整个文件夹拷走。

Q: 用了 Mod 会不会被封？
A: 官方对 Mod 持开放态度，但使用须遵守 Fatshark 官方 modding 政策（涵盖对其它玩家的影响、
   服务稳定性与性能、绕过进度或付费内容等），
   政策原文：https://forums.fatsharkgames.com/t/darktide-modding-policy/75407 ，后果自负。

Q: 游戏运行时提示操作被拒？
A: 防呆保护：游戏运行中动 Mod 文件可能导致游戏崩溃。关闭游戏后再操作。

Q: 游戏崩溃了怎么排查？
A: 崩溃多为 mod 冲突或与游戏版本不兼容。点「关于」页「打开控制台日志文件夹」
   （Steam 版 %APPDATA%\Fatshark\Darktide\console_logs，Xbox / Game Pass 版为
   %APPDATA%\Fatshark\MicrosoftStore\Darktide\console_logs，两处互不通用，程序自动定位），
   用记事本打开最新的 console-*.log，把报错片段发给 mod 作者求助。
   更快的办法：把日志拖进管理器窗口（或点「关于」页「实验：日志预览」），
   它会给出崩溃/异常卡片，并列出「MOD 错误排行」——按报错次数从多到少排列，
   点一条就筛出那个 mod 的日志行，照着更新或停用它即可；
   排行里标「版本不兼容」的 mod，说明它的 hook 目标在当前游戏版本里已不存在
   （作者还没适配新版本），优先更新它；作者没更新就先停用；
   另有一组「被 mod 吞掉的引擎错误」——这些是游戏侧的报错，被某些 mod 拦下了，
   排查诡异问题时留意它可能掩盖了线索；
   日志很大时只会分析末尾（信息栏会写明「前 N 行未载入」）——最近的报错都在最后，够用；
   或逐个禁用最近添加的 mod 定位冲突源（操作均有自动备份，可随时恢复）。

Q: 出了问题要提供什么？（说不清自己环境时尤其管用）
A: 直接发管理器文件夹里的 app.log —— 它已记录「游戏目录自动识别」的全部候选
   （Steam 库 / <盘>:\XboxGames，逐个标存在·有效）与「日志目录探测」结果
   （命中哪个版本 + 实际路径，没找到则列出候选目录和 APPDATA 实际值）。
   找不到游戏目录、日志功能用不了、Xbox / Game Pass 版行为异常，靠这个文件一眼定位。
   「关于」页「导出崩溃报告」另有一个 zip（最新控制台日志 + 崩溃转储 + 报告信息），
   是给不懂怎么修的玩家直接丢给有经验的人看的，里面只有游戏侧材料，不含管理器日志。

----------------------------------------
六、数据位置一览
----------------------------------------
· 启停清单：游戏目录 mods\mod_load_order.txt
· 自动备份：管理器文件夹 backups\
· Mod 备注：管理器文件夹 notes.json
· 方案预设：管理器文件夹 profiles\
· 管理器库：管理器文件夹 my_mods\
· 运行日志：管理器文件夹 app.log（★ 反馈问题时请附上，内含环境诊断）
· 界面缓存：管理器文件夹 webview_profile\（窗口设置与"引导已看过"之类的本地状态，
  删掉只会让引导重走一遍，不影响任何 Mod 数据）
