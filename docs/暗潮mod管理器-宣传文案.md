## 正文

### 开场：说到装 Mod，你是不是也这样过？

想给《战锤40K：暗潮》装 Mod 玩，结果：
- 下载了加载器、汉化、补丁工具……一堆东西，照着教程一步步塞，装到一半不知道哪步错了
- 好不容易跑起来，导入整合包又把游戏目录弄得乱七八糟，换包=重装
- 游戏一更新，Mod 全没了，还得手动重新打补丁
- 列表里全是英文名，哪个 mod 是干嘛的？全靠猜

**现在这些都可以省了。**

### 这是什么？

**暗潮 MOD 管理器（DMM）**——一款给《暗潮》设计的轻量 Mod 管理器，基于 Darktide Mod Framework 的加载机制，只做"壳"，不碰游戏本体。

**新玩家下载后即可一键开玩，老玩家换包如换衣服。**

### 核心亮点

**① 内置全套 DMF 框架，一键安装**
加载器 base + DMF（含中文汉化）+ dtkit-patch + 自动装载插件，全部内置。打开管理器，顶部提示缺什么，点一下「⚡ 一键安装 DMF」，框架自动装好并激活。不用再去各种网站东拼西凑。

**② 整合包一键导入，双模式随便换**
zip / 7z / rar / tar.gz 全支持，自动识别包结构，兼容网上主流整合包。
- **替换导入（推荐）**：旧 mods 整体归档备份，mods 始终保持干净的一套，根目录残留自动收走
- **合并叠加**：包内 mod 加进现有 mods，想自己搭配也行

**③ 换包有后悔药：全自动归档备份**
每次导入/恢复操作前自动备份，备份页一键换回任意历史整合包。手滑删错？误操作？点一下找回。

**④ 中文显示名，告别"猜 mod"**
自动读取 mod 本地化文件，列表直接显示中文名（自动拾取、智能队友AI…），英文原名作副标题。想找什么 mod，一搜就有，中英文都能搜。

**⑤ 方案预设，一键切换配置**
把启停+顺序存成方案：打宝流、拍照流、纯净流……随时一键切换。同一套 mod，多种玩法配置，秒切。

**⑥ 防崩溃设计，游戏更新不慌**
绝不动 patch_999 / mod_loader 关键文件。游戏更新后 mods 被官方禁用是正常现象——打开管理器点「安装补丁」，一键恢复，mod 文件都还在。

**⑦ 细节拉满**
右键菜单（打开文件夹 / 复制 mod 名 / 备注 / 删除进回收站 / 清理残留）、拖拽排序、自动补丁、单实例保护、每次写入自动备份、窗口位置记忆。

### 三步开玩

1. **解压**下载的压缩包，双击 `DarktideModManager.exe`（自动搜索 Steam 库定位游戏目录）
2. 点 **「⚡ 一键安装 DMF」** 装框架（只做一次）
3. 点 **「📦 导入整合包」** 选你的整合包 → 开玩

不想用整合包？直接「＋ 导入 mod」加单个 mod，自己搭配。

### 常见问题

**Q：游戏更新后 Mod 全没了？**
A：正常现象（官方机制）。打开管理器点「安装补丁」即可恢复，Mod 文件都还在。

**Q：杀毒软件报毒？**
A：Python 打包程序的常见误报，添加信任即可。源码全开源，无恶意行为。

**Q：用了 Mod 会不会被封？**
A：官方对 Mod 持开放态度，但联机使用第三方 Mod 需遵守游戏规则，后果自负。
