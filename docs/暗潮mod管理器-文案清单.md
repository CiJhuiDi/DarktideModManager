## 二、后端提示消息（app.py，会显示在界面上的）

### 成功消息
- 补丁已激活 / ✓ 自动装载：补丁已重新打上 / ✗ 自动打补丁失败
- ✓ 补丁已安装，mods 已激活 / ✓ 补丁已卸载，…（启动游戏不会自动恢复，mods 保持禁用）
- 游戏启动中，请稍候…
- ✓ DMF 安装完成（N 个组件），补丁已激活，mods 已就绪
- ✓ 整合包已生效：N 个 mod 就绪（原 N 个旧 mod 已归档到 backups/pack_backup_时间戳/，可随时找回）
- ✓ 整合包导入完成：新增/更新 N 个 mod（覆盖 N 个，旧版已备份）…，加载器/工具文件 N 个
- ✓ 已恢复备份 X：N 项（当前 mods 已归档到 pack_backup_时间戳），补丁已激活，mods 已就绪
- 已删除备份 X

### 错误提示
- 未找到 tools\dtkit-patch.exe，无法操作补丁
- 游戏正在运行，请先关闭游戏再操作补丁 / 再安装 DMF / 再恢复
- 未设置正确的游戏目录（请先到「关于」页设置）
- 游戏已在运行 / 未找到 Darktide.exe，请检查游戏文件完整性 / 未检测到 Steam 客户端，请先启动 Steam 并登录
- 压缩包包含非法路径，已拒绝
- 不是有效的 zip 文件（文件损坏或格式不对）
- 解压 rar 需要系统安装 WinRAR 或 7-Zip（未检测到）…
- 压缩包内没有 .mod 文件，不是 DMF mod 包（整个整合包请用「导入整合包」）
- 检测到整合包结构，请用「导入整合包」流程
- 压缩包内没有 mods/ 或加载器文件，不是暗潮整合包（单个 mod 请用「导入 mod」）
- 内置 DMF 组件缺失（打包不完整），请重新下载管理器
- 备份不存在或不是整合包归档 / 目录不存在 / 该目录不是暗潮游戏目录（需包含 mods 或 bundle 文件夹）
- 预设名不能为空 / 预设不存在

### 其他
- 单实例提示：暗潮 Mod 管理器已经在运行中。请查看任务栏或系统托盘。
