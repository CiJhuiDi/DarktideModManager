# DMM 暗潮 Mod 管理器 · Demo 展示文档

> 配套 `demo\` 演示验收环境（v0.3.1 Beta）。
> 用途：拍宣传视频 / 新版 exe 验收 / 向玩家演示功能。
> 演示环境是**假游戏目录**（demo\game），不碰真实游戏，可放心操作。

---

## 一、环境准备

```powershell
# 1. 一键重置演示环境（清空 → 重建示例 mod → 复制最新 exe）
python tools\reset_demo.py

# 2.（可选）生成演示产物：归档备份 + 整合包 zip
python tools\pack_demo.py
```

重置后 demo 目录结构：

```
demo\
├── DarktideModManager.exe   ← 最新构建
├── config.json              ← 已指向 demo\game，主题预置 pleasure 紫
├── game\                    ← 假游戏目录（mods\ + binaries\ + tools\ + bundle\）
│   └── mods\                ← 15 个示例 mod + base/dmf 系统组件 + 启停清单
├── backups\                 ← 演示备份（含 pack_demo 生成的归档）
└── profiles\                ← 演示预设
```

**示例 mod 场景一览**（build_demo.py 生成）：

| 场景 | mod | 说明 |
|---|---|---|
| 中文显示名 | AutoLoot 自动拾取 / BetterBots 智能队友AI / NumericUI 数值UI | 列表显示中文名 + 英文副标题 |
| 依赖正常 | Scoreboard 计分板（依赖 sb_core + ui_core） | 无徽标 |
| 缺依赖 | MissingDep 缺失依赖示例（依赖 lib_missing） | 红色 🔴 缺依赖徽标 |
| 循环依赖 | CycleA ↔ CycleB | 橙色 🔄 循环徽标 |
| 顺序扩展 | Scoreboard 本体 + ScoreboardDamage/ScoreboardAbility 扩展 | 正常排布无提示；拖乱顺序可演示 📌 顺序建议 |
| 版本差异 | OldMod 旧版mod（0.5.0） | 演示整合包导入时的「更新」行 |
| 禁用 | DisabledMod 已禁用示例 | 清单里 -- 注释，默认灰显 |
| 无版本 | NoVersion 无版本示例 | 副标题不显示版本 |

## 二、展示流程（按幕演示，约 10 分钟）

> 叙事主线：**这是什么 → 怎么装 mod → 装完体检 → 状态可存可找回 → 安全 → 彩蛋**。
> 开场 30 秒内必须让观众看到 mod 列表（核心画面），主题皮肤是彩蛋放后面。

### 第 1 幕 · 启动与界面总览（30 秒，快速带过）
1. 双击 `demo\DarktideModManager.exe`
2. **预期**：窗口打开**零闪烁**，首帧即正确主题；顺嘴一句「还带 7 套主题皮肤，最后再看」
3. 别在主题上停留，立刻切到 Mod 管理页展示 mod 列表——让观众 30 秒内看懂「这是暗潮 mod 管理器」

### 第 2 幕 · Mod 管理（2 分钟，核心场景）
1. 列表显示**中文显示名**（自动拾取/智能队友AI/数值UI），副标题为英文名 + 版本号
2. 搜索框输入「计分板」→ 过滤出 Scoreboard 系列；筛选「已启用/已禁用」
3. 拖拽 AutoLoot 调整顺序 → 顶部出现「● 有未保存的修改」→ 「撤销」/「保存修改」
4. 右键 AutoLoot → 菜单：打开文件夹 / 复制 mod 名 / 备注…（加备注后显示 `自动拾取(备注)`）/ 删除 mod 文件（进回收站可找回）/ 从清单移除（清理残留）
5. 右键 →「☑ 多选模式」：勾选多个 mod → 批量启用/禁用/删除

### 第 3 幕 · DMF 框架（1 分钟，新手刚需）
1. 顶部横幅：DMF 已就绪状态 /「🔄 重新安装框架」覆盖更新（旧文件自动备份）
2. 「安装补丁」「卸载补丁」「恢复自动装载」逐个演示
3. 话术：「不用手动折腾框架，一键装好，游戏更新自动禁用也有提示」

### 第 4 幕 · 导入整合包（2 分钟，重头戏）
1. 先用 `python tools\pack_demo.py` 生成 `demo\演示整合包_v0.3.0.zip`（如果还没生成）
2. 「＋ 导入」→「导入 Mod/整合包」→ 选 zip
3. **预期**：弹差异对比预览——新增（zip 里的 mod）/ 更新（OldMod 版本差异）/ 移除（当前有而 zip 没有）/ 相同
4. 确认导入 → 提示旧文件已归档到 backups 可找回 → 列表刷新
5. 顺带演示「导入文件夹」：选 demo\game\mods 下任意 mod 文件夹

### 第 5 幕 · 依赖检查（1 分钟，导入后的「体检」）
1. 列表直接看徽标：MissingDep 红色🔴缺依赖、CycleA/CycleB 橙色🔄循环
2. 把 ScoreboardDamage 拖到 Scoreboard 前面 → 蓝色📌顺序建议（扩展应在本体之后）
3. 展示完拖回原位（或点撤销）
4. 话术：「装完自动体检，哪个 mod 缺爹、哪个循环打架、顺序对不对，一眼看穿」

### 第 6 幕 · 导出（30 秒）
1. 「📤 导出」三模式：全部导出 / 按启用导出 / 仅导出清单（干净 mod_load_order.txt）
2. 导出后点「打开导出目录」

### 第 7 幕 · 预设与备份（2 分钟，「状态可存可找回」一组讲）
0. **开场直接用现成的**：预设页已内置三组玩法预设——「QOL · 生活统计」（计分板/数据统计）、「OB · 观赛模式」（敌人轮廓/特效去除）、「轻松游戏 · 自动辅助」（自动拾取/自动开火）——选自丁香整合包 78 个精选 mod
1. 点「OB · 观赛模式」→ 应用 → 弹**差异预览**（将启用/将禁用列表）→ 确认应用
2. 调整几个 mod 启停 →「＋ 将当前状态存为预设」
3. 切备份页：清单备份（自动产生）+ 整合包归档备份（pack_demo 产物，若已复制）
4. 删除一个 mod 再「恢复此备份」→ 展示找回能力
5. 话术：「状态存成预设随时切，删错了备份一键找回，导入前还有预览防手滑」
6. 注意：三组预设引用的是真实 mod 名，demo 假环境应用后会出现残留条目——这是功能演示，演示完跑 reset_demo.py 或恢复原清单即可；真实环境直接把这 3 个 json 拷到 exe 旁 profiles\ 就能用

### 第 8 幕 · 游戏防呆（30 秒，演示亮点）
1. 关于页 →「🎮 模拟游戏运行」
2. **预期**：切回 Mod 管理页，导入/删除/开关/保存/拖拽**全部变灰禁用**；后端 API 同时拦截
3. 「停止模拟」恢复
4. 话术：「游戏开着的时候所有写操作自动锁死，不会手滑把 mod 删了」

### 第 9 幕 · 主题系统（1 分钟，彩蛋收尾）
1. 关于页 → 主题设置：切换 7 套主题看渐变方向变化（对角/水平/垂直/径向）
2. 点「🎲 随机」立即换肤；勾选「每次启动时随机主题」后重启 exe 演示
3. 加分项：上传一张图 →「应用自定义主题」→ 暗/亮模式切换 →「移除」
4. 话术：「功能讲完，最后送个彩蛋——7 套皮肤随便换，还能用你自己的图当背景」

### 第 10 幕 · 关于页（30 秒，收尾）
1. 版本信息、游戏目录/mods 目录/日志路径快捷打开
2. 「🌐 GitHub」按钮跳转项目主页

## 三、新版 exe 验收检查清单

发布新版本后跑一遍（对照上面对应幕）：

- [ ] 启动零闪烁，主题/渐变/自定义背景按 config 生效
- [ ] 主题 7 套可切换、随机生效、浅色下选中项不刺眼
- [ ] 中文显示名 / 搜索 / 筛选正常
- [ ] 启停开关 + 拖拽排序 + 保存/撤销正常
- [ ] 右键菜单全部项可用（备注增删、删除进回收站、清残留）
- [ ] 多选模式批量操作正常
- [ ] 缺依赖/循环/顺序徽标正确显示
- [ ] 导入 zip 差异对比（新增/更新/移除/相同）正确
- [ ] 导入文件夹 / 清单 txt 正常
- [ ] 导出三模式产物正确
- [ ] 预设保存 + 应用（含差异预览）正常
- [ ] 备份页：清单备份恢复（含预览）、归档备份恢复
- [ ] 模拟游戏运行 → 写操作全部禁用；停止后恢复
- [ ] DMF 一键安装 / 重新安装（force）/ 补丁安装卸载
- [ ] 备份保留策略：多次导入后旧备份被清理，总数不超上限

## 四、演示注意事项 / 坑

1. **演示前先 reset_demo.py 重置**，否则 demo 里可能残留上次演示的改动（config 主题、备份等）
2. **拍视频时先关掉 Clash 代理**（演示「打开文件夹」等本地操作不受影响；GitHub 按钮需要网络）
3. 演示整合包 zip 名带 `_v0.3.0` 是 pack_demo.py 写死的，功能与版本无关，介意可手动改名
4. 备份保留策略演示：连续导入 2-3 次大 zip，看「自动清理最旧备份」提示
5. 真实环境展示（备份页恢复/导入整合包）：把 `demo\backups\pack_backup_<ts>` 整个文件夹复制到真实管理器 exe 旁 `backups\`，或用 `演示整合包_v0.3.0.zip` 直接导入——见 pack_demo.py 输出提示
6. 防呆幕必须在所有写操作演示完之后再演（一旦模拟运行，所有按钮会锁死）
